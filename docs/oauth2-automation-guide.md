# OAuth2 Automation Guide for Authentik

This guide covers the automated OAuth2 application creation process using Authentik's REST API.

## 🚀 Quick Start (Fully Automated)

Run the complete automation script:

```bash
./scripts/setup-oauth2-automation.sh
```

This script will:
1. ✅ Check Docker and service status
2. ✅ Install Python dependencies
3. ✅ Create Authentik API token (interactive)
4. ✅ Create OAuth2 application via API
5. ✅ Update environment variables
6. ✅ Restart FastAPI services
7. ✅ Test OAuth2 integration

## 📋 Manual Steps (If Needed)

### 1. Get Authentik API Token

```bash
python scripts/get-authentik-token.py
```

This will:
- Prompt for Authentik admin credentials (default: akadmin)
- Login to Authentik web interface
- Create an API token for automation
- Save the token to `.env` file

### 2. Create OAuth2 Application

```bash
python scripts/auto-create-oauth2-app.py
```

Environment variables (automatically configured):
```bash
export AUTHENTIK_URL="https://localhost:9443"
export AUTHENTIK_API_TOKEN="your_api_token_here"
export OAUTH_APP_NAME="FastAPI Client"
export OAUTH_CLIENT_ID="fastapi-client"
export OAUTH_REDIRECT_URIS="http://localhost:8000/api/auth/callback"
export OAUTH_SCOPES="openid,email,profile,rag:api"
```

### 3. Test OAuth2 Integration

```bash
python scripts/test-oauth2-flow.py
```

## 🔧 Technical Details

### API Endpoints Used

The automation uses these Authentik REST API endpoints:

1. **Authentication Flows**: `GET /api/v3/flows/instances/`
2. **Certificates**: `GET /api/v3/crypto/certificatekeypairs/`
3. **Applications**: `POST /api/v3/core/applications/`
4. **OAuth2 Providers**: `POST /api/v3/providers/oauth2/`
5. **Application Updates**: `PATCH /api/v3/core/applications/{id}/`

### OAuth2 Provider Configuration

The script creates an OAuth2 provider with these settings:

```json
{
  "name": "FastAPI Client OAuth2 Provider",
  "authorization_flow": "default-authentication-flow",
  "client_id": "fastapi-client",
  "redirect_uris": ["http://localhost:8000/api/auth/callback"],
  "client_type": "confidential",
  "include_claims_in_id_token": true,
  "issuer_mode": "per_provider",
  "sub_mode": "hashed_user_id",
  "access_code_validity": "minutes=1",
  "access_token_validity": "minutes=5",
  "refresh_token_validity": "days=30"
}
```

### Application Configuration

```json
{
  "name": "FastAPI Client",
  "slug": "fastapi-client",
  "policy_engine_mode": "all",
  "meta_description": "OAuth2 application for FastAPI Client - Created automatically via API"
}
```

## 🔍 Troubleshooting

### Common Issues

1. **API Token Creation Fails**
   - Ensure Authentik is accessible at https://localhost:9443
   - Check admin credentials (default: akadmin/password)
   - Verify CSRF token extraction from login page

2. **OAuth2 Application Creation Fails**
   - Check API token validity
   - Ensure required flows and certificates exist
   - Verify network connectivity to Authentik

3. **FastAPI Integration Issues**
   - Restart FastAPI services after configuration changes
   - Check environment variables in docker-compose.yml
   - Verify OAuth2 client initialization

### Debug Commands

```bash
# Check Authentik API connectivity
curl -k -H "Authorization: Bearer $AUTHENTIK_API_TOKEN" \
  https://localhost:9443/api/v3/flows/instances/

# Check OAuth2 provider creation
curl -k -H "Authorization: Bearer $AUTHENTIK_API_TOKEN" \
  https://localhost:9443/api/v3/providers/oauth2/

# Test FastAPI OAuth2 status
curl http://localhost:8000/api/auth/status
```

## 🔐 Security Considerations

1. **API Token Management**:
   - API tokens are stored in `.env` file
   - Tokens have no expiration by default
   - Rotate tokens regularly in production

2. **Client Secret Security**:
   - Client secrets are auto-generated by Authentik
   - Stored securely in environment variables
   - Not logged or displayed in plain text

3. **SSL/TLS**:
   - Development uses self-signed certificates
   - Production should use valid SSL certificates
   - SSL verification disabled for localhost testing
